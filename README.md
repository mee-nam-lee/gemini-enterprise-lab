## ✨ 주요 실습 내용

- **검색 & 기본 기능 (Core AI Assistant & Live Search)**: 시장 트렌드, 경쟁사 분석 및 대화 공유
- **문서 및 데이터 분석 (Multimodal Analysis)**: Excel 설문/매출 데이터 분석, PowerPoint 요약 및 Google Sheets 연동
- **비주얼 기획 & 생성 (Canvas & Media Generation)**: Canvas 기반 Google Slides 자동 기획/생성 및 맞춤 이미지 생성
- **리서치 어시스턴트 (NotebookLM)**: 대량의 문서 기반 심층 리서치 및 오디오 요약
- **에이전트 시스템 (Agent Systems)**: Agent Designer 노코드 에이전트, 스케줄링, 채용 프로세스 멀티 에이전트 연동, BigQuery CA 에이전트
- **도구 확장 및 보안 (Tools & Security)**: MCP(Model Context Protocol) 연동 및 Model Armor 데이터 보호
